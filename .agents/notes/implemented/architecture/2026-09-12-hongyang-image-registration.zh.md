# Agent Note: provider 负责截图登记

Status: implemented

[English](2026-09-12-hongyang-image-registration.md) | 中文

## Problem

把截图字段重新拼成句子可能丢失交易身份和时间。接受缺失的收款方或不完整的模型输出，可能将不完整证据转为财务登记。

## Decision

财务 provider 在共用的交易／分配写入路径之前校验截图字段。金额转换和格式化在 provider 内完成，日期保留给定时间，交易单号独立存储。收款方缺失、金额无效及日期无效均在数据库写入前拒绝。未识别的商户或费项名称产生待确认收款。

钉钉桥接层使用财务服务的类型化方法和可选视觉客户端。LLM 适配器在将 JSON 交给校验前要求明确的成功终止事件。桥接层报告失败，不声称登记成功。

## Alternatives considered

从截图字段重新拼出自由文本可复用文字解析器，却会丢失字段分隔。共用的结构化 provider 写入路径保留证据，且无需重复分配逻辑。接受缺失收款方可提高表面识别率，但不能确认配置中的收款主体。

## Consequences

使用实际数据库的桥接测试固定存储金额、时间戳、交易单号、分配和回复文案。无效证据测试固定零写入；LLM 测试拒绝失败、取消、截断和缺少终止事件。这些测试不证明真实钉钉连通，也不证明第 6、7 步完整验收通过。宿主挂载、持久化的用户会话、消息去重、平台交易合并和网页图片工具仍需接入。
