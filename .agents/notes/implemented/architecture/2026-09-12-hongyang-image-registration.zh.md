# Agent Note: provider 负责截图登记

Status: implemented

[English](2026-09-12-hongyang-image-registration.md) | 中文

## Problem

把截图字段重新拼成句子可能丢失交易身份和时间。接受缺失的收款方或不完整的模型输出，可能将不完整证据转为财务登记。

## Decision

财务 provider 在共用的交易／分配写入路径之前校验截图字段。金额转换和格式化在 provider 内完成，日期保留给定时间，交易单号独立存储。收款方缺失、金额无效及日期无效均在数据库写入前拒绝。未识别的商户或费项名称产生待确认收款。

钉钉桥接层使用财务服务的类型化方法和可选视觉客户端。LLM 适配器在将 JSON 交给校验前要求明确的成功终止事件。桥接层报告失败，不声称登记成功。宿主入口连接认证图片下载器与显式配置的 provider/model 路由。SQLite 第 2 版草稿将提取字段和用户文字一起保存；升级时保留第 1 版文字草稿和卡片。Provider 预览不写入，拒绝冲突的文字金额，并在确认时重新校验截图与精确候选。持久化的会话版本防止仍在执行的识别覆盖后来的消息或取消操作。

钉钉确认使用[工作台审批队列](2026-09-15-hongyang-workbench-approval.zh.md)，只有工作台决定才提交财务记录。

## Alternatives considered

从截图字段重新拼出自由文本可复用文字解析器，却会丢失字段分隔。共用的结构化 provider 写入路径保留证据，且无需重复分配逻辑。接受缺失收款方可提高表面识别率，但不能确认配置中的收款主体。

## Consequences

使用实际数据库的桥接测试固定存储金额、时间戳、交易单号、分配和回复文案。无效证据测试固定零写入；LLM 测试拒绝失败、取消、截断和缺少终止事件。这些测试不证明真实钉钉连通，也不证明第 6、7 步完整验收通过。Loader 组合使用真实宿主服务和外部网络/模型夹具，在包内 `tests/expected/` 固定图片卡片；该桥接层不生成 harness Session 转录。重新打开和取消测试覆盖持久图片草稿与晚到的提取结果。真实模型和手机验收、平台交易合并和网页图片工具仍需接入。
